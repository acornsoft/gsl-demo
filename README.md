# gsl-demo

Demo platform for **Gotham Savings and Loan (GSL)**, a fictional bank used as a practice model. All data is synthetic.

- Infra: Bicep + Azure Developer CLI (azd), deployed by GitHub Actions with OIDC (no stored secrets).
- Work items: Azure DevOps (`acornsoft/ai.acornsoft`), linked with `AB#<id>`.
- Nothing merges to `main` without David's approval.
